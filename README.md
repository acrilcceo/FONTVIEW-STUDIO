# FONTVIEW STUDIO

**FONTVIEW STUDIO** is a deterministic, rule-based kinetic typography engine designed to generate precise motion timelines for captions, reels, and short-form video content.

Built and maintained by **Sambit Ghosh**.

---

## 🚀 Features

- Deterministic kinetic caption generation
- Safe-zone aware layouts (75% motion-safe area)
- Social-media optimized pacing (155 WPM)
- PRIMARY / SECONDARY word hierarchy
- Multiple font modes (Single, Combination, Free)
- Motion presets for short-form content
- Clean JSON-based motion output
- No external AI, APIs, or keys required

---

## 🛠 Tech Stack

- TypeScript
- React
- Vite
- Deterministic rule-based motion engine
